# Reprise — RPG Origins
Branche : claude/rpg-origins-complete (orpheline). Ne jamais pousser ailleurs, ni sur main, ni déployer le site.
État : jeu complet jouable (61 scènes, 12 quêtes, 27 décors, 37 sprites, audio procédural, sauvegardes, éditeur). Deux fins vérifiées par autoplay (voir TESTS.md).
Budget images : ~0,75 € engagés / 15 € (voir `npm run image:status`).
Reste : finition optionnelle (art titre, planches de compagnons), rapport de livraison. Limites connues : pas de remappage des touches, pas de manette, pas de partie manuelle complète testée.
Commandes : npm run build | validate | coverage | test:images ; e2e dans tools/e2e (E2E_BASE=url).
