# Références du style n°9

Références visuelles officielles du style non-pixel art n°9 de RPG Origins. Description complète et règles d'usage : `CLAUDE.md`.

- `style9-reference-decor.png` : décor de forêt (1672×941).
- `style9-reference-character.png` : planche de personnage en 8 vues (1536×1024).

Conversion sans perte depuis les JPEG fournis (le PNG permet à `npm run image:inventory` de les afficher en tête de planche).
Ces fichiers sont la source de vérité du style : ne pas les modifier sans demande explicite de l'utilisateur.
